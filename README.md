# 🛒 Amazon Clone

A fully functional Amazon e-commerce website clone built for learning and demonstration purposes. This project replicates core features of Amazon like product listings, user authentication, shopping cart, and checkout.

## 🚀 Features

- User Authentication (Login/SignUp)
- Browse Products by Category
- Product Search
- Add to Cart / Remove from Cart
- Checkout Page
- Order Summary
- Responsive Design

## 🧰 Tech Stack

**Frontend:**
- HTML / CSS
- Redux (optional for state management)
- Bootstrap / Tailwind CSS (for styling)
